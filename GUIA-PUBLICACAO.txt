ATUALIZAÇÃO DO SITE
1. Extraia o ZIP.
2. No repositório atual, Code > Add file > Upload files.
3. Arraste os arquivos e a pasta assets juntos, sem a pasta externa do ZIP.
4. Commit changes na branch main. Não apague .github/workflows.
5. Em Actions, confira se a publicação terminou com sucesso.
